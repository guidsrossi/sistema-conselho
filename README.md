# Sistema de Apresentação de Estudantes

Abra o arquivo `index.html` no navegador.

Como usar:
1. Coloque as fotos dentro da pasta `alunos`, separadas por turma. Exemplo: `alunos/1A/MARIA.jpeg`, `alunos/1B/JOAO.jpeg`.
2. Abra `index.html`.
3. O sistema tenta carregar as fotos automaticamente da pasta `alunos`.
4. Se precisar, use **Carregar fotos extras** para selecionar outra pasta manualmente.
5. Use filtros, busca, setas do teclado e botão **Tela cheia**.

O sistema já contém os alunos lidos da planilha enviada. Ele tenta associar fotos mesmo com pequenas diferenças de digitação no nome do arquivo.
